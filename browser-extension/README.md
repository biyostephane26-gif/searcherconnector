# Searcher Connector — Extension navigateur

## Installer (mode développeur)

1. Ouvre `chrome://extensions`
2. Active **Mode développeur**
3. Clique **Charger l'extension non empaquetée**
4. Sélectionne ce dossier (`browser-extension/`)
5. Colle ton token (Paramètres → Extension navigateur)

## Comportement

- **Tous les sites** (LinkedIn, Upwork, sites d’entreprise…) : pré-remplissage automatique. Le clic d’envoi reste le tien.
- **Greenhouse / Lever uniquement** : si tu actives « Soumission 100% autonome » dans le popup, l’extension remplit **et** envoie.

Le token ne donne jamais accès à ton mot de passe : il identifie seulement ton profil pour remplir les champs.
